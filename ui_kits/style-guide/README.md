# Style guide & colour picker UI kit

Two sibling sites on rendata.nl: the data-vis style guide (RenRMT/style-guide, Jekyll + just-the-docs with the "ren" colour scheme) and the colour picker (RenRMT/color-picker). Combined here because they share one sidebar-docs frame and the palette is the guide's Colour section.

Screens: Guide home (short version, callout legend) · Principles (Callout, RulePair, BigNumber) · Colour (Swatch rows, sequential and diverging builders, config-error Alert).

Copy is verbatim from the repos. The picker in the original uses Arial and 8px radii; here it adopts the REN type and 6px radius. Nav items marked "not in kit" exist in the guide but weren't recreated.
